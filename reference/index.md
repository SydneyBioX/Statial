# Package index

## All functions

- [`Kontextual()`](https://sydneybiox.github.io/Statial/reference/Kontextual.md)
  : Evaluation of pairwise cell relationships, conditional on a 3rd
  population.
- [`calcContamination()`](https://sydneybiox.github.io/Statial/reference/calcContamination.md)
  : Calculate the level of marker contamination of each cell
- [`calcStateChanges()`](https://sydneybiox.github.io/Statial/reference/calcStateChanges.md)
  : First layer wrapper function to build linear models measuring state
  changes
- [`distanceCalculator()`](https://sydneybiox.github.io/Statial/reference/distanceCalculator.md)
  : Calculate pairwise distance between cell types
- [`getAbundances()`](https://sydneybiox.github.io/Statial/reference/getAbundances.md)
  : Wrapper to calculate imhomogenous K function between a cell and
  surrounding types on each image
- [`getDistances()`](https://sydneybiox.github.io/Statial/reference/getDistances.md)
  : Wrapper to calculate pairwise distance between cell types by image
- [`getMarkerMeans()`](https://sydneybiox.github.io/Statial/reference/getMarkerMeans.md)
  : Extract the average expression for all markers for each cell type in
  each region defined by lisaClust
- [`getParentPhylo()`](https://sydneybiox.github.io/Statial/reference/getParentPhylo.md)
  : Extract parent and all children from a Phylo object
- [`isKontextual()`](https://sydneybiox.github.io/Statial/reference/isKontextual.md)
  : Test whether an object is a kontextualResult
- [`kerenKontextual`](https://sydneybiox.github.io/Statial/reference/kerenKontextual.md)
  : Kontextual results from kerenSCE
- [`kerenSCE`](https://sydneybiox.github.io/Statial/reference/kerenSCE.md)
  : MIBI-TOF Breast cancer intensities
- [`kontextCurve()`](https://sydneybiox.github.io/Statial/reference/kontextCurve.md)
  : Evaluation of Kontextual over a range of radii.
- [`kontextPlot()`](https://sydneybiox.github.io/Statial/reference/kontextPlot.md)
  : Plotting the original and kontextual L values over a range of radii.
- [`kontextualTest()`](https://sydneybiox.github.io/Statial/reference/kontextualTest.md)
  : Test Kontextual relationships between conditions or with survival
- [`makeWindow()`](https://sydneybiox.github.io/Statial/reference/makeWindow.md)
  : Creates a window for a PPP object
- [`parentCombinations()`](https://sydneybiox.github.io/Statial/reference/parentCombinations.md)
  : Create all combinations of cell type relationships from a list of
  parents
- [`plotStateChanges()`](https://sydneybiox.github.io/Statial/reference/plotStateChanges.md)
  : Visualise Cell-Cell Marker Relationships
- [`prepMatrix()`](https://sydneybiox.github.io/Statial/reference/prepMatrix.md)
  : Convert Kontextual or state changes result to a matrix for
  classification
- [`relabelKontextual()`](https://sydneybiox.github.io/Statial/reference/relabelKontextual.md)
  [`relabel()`](https://sydneybiox.github.io/Statial/reference/relabelKontextual.md)
  : Cell permutation for Kontextual
